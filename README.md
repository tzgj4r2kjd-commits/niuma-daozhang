# 牛马到账计时器

每一秒上班，都在为下班充值。单文件 HTML，纯本地计算，零依赖。

- 实时到账滚动（精确到 0.0001 元）
- 距离下班倒计时 + 工作进度
- 摸鱼回收器：带薪拉屎/喝水/发呆实时换算白嫖金额
- 加班血亏模式：过点自动变红「老板已欠你」
- 周五快乐溢价 ×1.5（心理倍率）
- 老板来了：一键伪装「工作热爱度 100%」
- 下班越狱动画 + 一键生成今日战绩长图
